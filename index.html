Predstavitev projekta

Fotografija kot umetnost in tehnologija

Fotografija je pomemben del sodobnega sveta, saj omogoča ohranjanje spominov, dokumentiranje dogodkov in ustvarjanje umetniških del. Z njo lahko predstavimo naravo, arhitekturo, ljudi, živali in številne druge motive. Vsaka fotografija je rezultat opazovanja, izbire motiva in premišljene uporabe svetlobe.

Namen te projektne naloge je izdelati interaktivno spletno galerijo, ki obiskovalcem omogoča pregledovanje fotografij in raziskovanje različnih kategorij. Spletna stran je zasnovana tako, da je njena uporaba preprosta, vsebina pa pregledna in dostopna tudi na manjših zaslonih.

Pri izdelavi uporabljamo HTML za strukturo strani, CSS za oblikovanje in JavaScript za interaktivne funkcije. HTML določa razdelke, naslove, besedilo, slike in gumbe. CSS skrbi za barve, razmike, mrežno postavitev, odzivnost ter animacije. JavaScript pa omogoča iskanje, razvrščanje, označevanje priljubljenih fotografij in povečan prikaz.

Pomemben del spletnega oblikovanja je tudi uporabniška izkušnja. Obiskovalec mora hitro razumeti, kako stran deluje, kako najde želeno vsebino in kako se vrne na začetno stran. Jasna navigacija, dovolj kontrasta in berljivo besedilo pomagajo ustvariti prijetno izkušnjo.

Spletno galerijo je mogoče v prihodnosti še nadgraditi. Dodamo lahko obrazec za nalaganje lastnih fotografij, dodatne kategorije, opise posameznih avtorjev in shranjevanje priljubljenih slik. Projekt tako prikazuje, kako lahko s kombinacijo osnovnih spletnih tehnologij ustvarimo uporaben in privlačen izdelek.

01. HTML — struktura

HTML določa vsebinske elemente, naslove, povezave, slike, gumbe in razdelke spletne strani.

02. CSS — oblikovanje

CSS določa barve, tipografijo, razporeditev, odzivni dizajn in vizualne učinke.

03. JavaScript — interaktivnost

JavaScript povezuje gumbe z dejanji ter omogoča iskanje, filtre, priljubljene slike in povečavo.

04. Odzivnost

Prilagodljiva postavitev omogoča uporabo galerije na računalniku, tablici in telefonu.

Ustvarjalni kotiček

Trije nasveti za boljše fotografije

Dobra fotografija se začne z opazovanjem. Pri fotografiranju lahko že nekaj preprostih odločitev naredi veliko razliko.

01

Opazuj svetlobo

Svetloba vpliva na barve, sence in vzdušje fotografije. Naravna svetloba zjutraj ali pozno popoldne je pogosto mehkejša, zato lahko poudari podrobnosti motiva.

02

Premisli o kompoziciji

Razporeditev elementov vpliva na to, kam gledalec najprej usmeri pogled. Poskusi spremeniti kot, razdaljo ali položaj glavnega motiva.

03

Pripoveduj zgodbo

Najbolj zanimive fotografije pogosto prikazujejo več kot samo predmet. Izberi motiv, ki vzbuja radovednost ali predstavlja poseben trenutek.
